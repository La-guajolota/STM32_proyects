# 📈 ADC Rampa Project

This project implements a ramp ADC (Analog-to-Digital Converter) on an STM32F411CEUx microcontroller. It uses a PWM signal to generate a ramp voltage and a comparator to determine the digital value. The result is displayed on a 7-segment display and sent over UART for verification.

## MCU 🤖

*   **MCU:** `STM32F411CEUx`
*   **Family:** STM32F4

## Peripherals Used ⚙️

*   **TIM1:** Generates a PWM signal to create the ramp voltage.
*   **TIM2:** Used to create a microsecond delay function.
*   **TIM3:** Generates an interrupt to refresh the 7-segment display.
*   **TIM4:** Used as an encoder interface to select the ADC mode.
*   **ADC1:** The internal ADC of the MCU is used to read the same analog input as the ramp ADC, for comparison.
*   **USART6:** Transmits the ADC readings (both from the ramp ADC and the internal ADC) to a computer.
*   **GPIO:**
    *   A set of GPIOs are used to drive a 7-segment display.
    *   Other GPIOs are used for a multiplexer and a comparator input.

## Application Logic 🧠

The application implements a ramp ADC, which works as follows:

1.  **Ramp Generation:** A ramp voltage is generated by feeding a PWM signal from `TIM1` to a low-pass filter (an RC circuit).
2.  **Comparison:** The ramp voltage is compared with the analog input signal using an external comparator. The output of the comparator is connected to a GPIO pin (`PA9`).
3.  **Conversion:** The `convert()` function increments the PWM duty cycle, which increases the ramp voltage. It continuously checks the output of the comparator. When the ramp voltage exceeds the analog input voltage, the comparator's output changes state, and the loop terminates. The final duty cycle value is the digital representation of the analog input.
4.  **Display:** The digital value is displayed on a 7-segment display using a custom library (`Seg7_mux.h`). The display is refreshed using an interrupt from `TIM3`.
5.  **Mode Selection:** An encoder connected to `TIM4` is used to select between two modes:
    *   **Continuous Mode:** The ADC conversion is performed continuously.
    *   **Interrupt Mode:** The ADC conversion is triggered by an external interrupt.
6.  **Verification:** The application also reads the same analog input using the MCU's internal ADC (`ADC1`). Both the ramp ADC value and the internal ADC value are sent over `USART6` for comparison and analysis.

## How to Use 🤔

1.  **Hardware Setup:**
    *   Connect an analog signal to the input of the ramp ADC (the comparator's input) and to the input of the internal ADC (`PA0`).
    *   Connect the PWM output (`PA8`) to an RC low-pass filter to generate the ramp voltage.
    *   Connect the output of the comparator to `PA9`.
    *   Connect a 7-segment display to the corresponding GPIO pins.
    *   Connect an encoder to the `TIM4` pins (`PB6`, `PB7`).
    *   Connect the `TX` pin of a USB-to-UART converter to `PA11`.
2.  **Software:**
    *   Open a serial terminal on your computer.
    *   Configure the serial port with the following settings:
        *   **Baud Rate:** 9600
        *   **Data Bits:** 8
        *   **Parity:** None
        *   **Stop Bits:** 1
3.  **Run:**
    *   Power on the STM32 board.
    *   The ADC value will be displayed on the 7-segment display.
    *   The ramp ADC value and the internal ADC value will be printed on the serial terminal.
    *   You can turn the encoder to switch between continuous and interrupt-based conversion modes.
